# Browser integration

Reserved for RustDM's future Chrome/Firefox extensions and native messaging
integration. No installable extension is present yet.

The planned extension transfers user-selected URLs and necessary browser request
context to our own native host. That host will use the same core engine as the
CLI and desktop UI. Message framing, permission boundaries, and capture decisions
will be documented and tested when this milestone starts.

See [the roadmap](../../ROADMAP.md).
